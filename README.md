# World Football Tracker

World Football Tracker is an unofficial iOS tournament companion for following the 2026 football competition.

The app lets users browse fixtures, groups, teams, venues, match times, and knockout rounds, then add selected fixtures to Calendar or Reminders.

## App Details

- App name: World Football Tracker
- Bundle ID: `com.sean.WorldCup`
- Platform: iOS
- Minimum iOS version: iOS 18.0
- Category: Sports
- Version: `1.0`
- Build: `1`
- TestFlight public link: https://testflight.apple.com/join/cJBzEJKQ

## Features

- Fixture list with match times, stages, teams, venues, and status fields
- Group tables for all 12 groups
- Team list with squad-note and manager fields ready for updates
- Tournament guide covering the format and app features
- Calendar events and Reminders for selected fixtures

## Privacy

World Football Tracker does not collect user data, does not track users, does not use ads, and does not require an account. Calendar and Reminders permissions are only requested when the user taps the matching fixture action.

## Disclaimer

World Football Tracker is independent and is not affiliated with FIFA, the World Cup, or the tournament organisers.
