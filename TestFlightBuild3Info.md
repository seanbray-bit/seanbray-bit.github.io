# TestFlight Build 3 Information

## Beta App Description

World Football Tracker is an unofficial tournament companion for following the 2026 football competition. Browse fixtures, groups, teams, venues, match times, knockout rounds, and stadium schedules.

Build 3 adds a real iPhone Home Screen widget. Testers can add the Next Match widget to their Home Screen to see the upcoming match countdown without opening the app.

This app is not affiliated with the tournament organisers.

## What To Test

Please test the new build 3 widget feature:

- Install build 3 from TestFlight.
- Long-press the iPhone Home Screen.
- Tap `+` and search for World Football Tracker.
- Add the Next Match widget.
- Try both the small and medium widget sizes.
- Check that the widget shows the next match, countdown, venue, and kick-off time clearly.
- Tap the widget and confirm it opens the app.
- Check that the widget text is readable on your wallpaper.

Also continue testing:

- Home screen countdown timer.
- Opening game spotlight.
- Featured Venues on the Home screen.
- Venues tab and stadium fixture lists.
- Fixtures, Groups, Teams, Venues, and Guide tabs.
- Calendar and Reminder buttons on fixture cards.
- Closing and reopening the app.

## Beta App Review Information

The app does not require an account. No login, subscription, payment, special hardware, or server setup is needed.

Build 3 includes a WidgetKit Home Screen widget for the next match countdown.

Suggested review steps:

1. Open the app.
2. Check the Home screen countdown and opening game spotlight.
3. Add the Next Match widget to the iPhone Home Screen.
4. Check the small and medium widget layouts.
5. Tap the widget to open the app.
6. Browse the Fixtures, Groups, Teams, Venues, and Guide sections.
7. Open a fixture and test the Calendar and Reminder buttons.
